<h1>سوپر جینکس</h1>

<h3>یک پنل کامل مرزبان، روی Railway، در ۵ دقیقه. بدون حتی یک خط ترمینال.</h3>

<p dir="rtl">
<b>۱۲ کانفیگ</b> آماده که برای همه‌ی اپراتورها تنظیم شدن، <b>پنل نمایندگی</b> با هر حجمی از ۱ مگابایت تا نامحدود،<br/>
صفحه‌ی ساب <b>JINX PASS</b> برای گوشی و کامپیوتر، و <b>ربات‌های نگهبانی</b> که هر ۱۵ ثانیه همه‌چی رو چک و خودشون تعمیر می‌کنن.<br/>
نه سرور می‌خواد، نه دامنه، نه سرتیفیکیت.
</p>

## <img src="readme-i-news.svg" width="34" height="34" align="center" alt=""/>&nbsp; تازه‌های نسخه‌ی ۱۴

<img src="readme-v14.svg" width="100%" alt="تازه‌های نسخه‌ی ۱۴"/>

> [!IMPORTANT]
> **نسخه‌ی ۱۴، خط‌به‌خط تست‌شده روی موبایل و کامپیوتر، بدون هیچ خطای صفحه**
> - دکمه‌ی **حمایت مالی** حالا یه جای ثابت گوشه‌ی پایین صفحه داره و دیگه هیچ‌وقت نمی‌پره، تکون نمی‌خوره و از صفحه بیرون نمی‌زنه
> - صفحه‌ی **ساخت پنل نمایندگی** از نو چیده شده: پکیج‌ها، فرم و پیش‌نمایش روی گوشی و کامپیوتر مرتب، و هیچ دکمه‌ای بیرون نمی‌زنه
> - **هر حجمی که بخوای:** انتخاب واحد **MB / GB / TB** برای ساخت، ویرایش و شارژ نماینده، از **۱ مگابایت** تا نامحدود
> - فرم کاربر خود مرزبان هم **حجم اعشاری** قبول می‌کنه (مثلاً `0.5` گیگ یعنی ۵۱۲ مگ)
> - دو کانفیگ **XHTTP** به روش Vodiwalker: Warp Speed با حالت `packet-up` و Quantum با حالت `stream-up`
> - **مسیر مخفی** کانفیگ‌ها (`/cdn/<شناسه>`) که برای هر پنل جداست
> - انتخاب **اپراتور** توی صفحه‌ی ساب، بهترین کانفیگ میاد بالای لیست
> - **قطعی کمتر:** اتصال بیکار تا ۱۰ دقیقه باز می‌مونه و نگهبان رم فقط از ۹۷٪ وارد عمل میشه

## <img src="readme-i-install.svg" width="34" height="34" align="center" alt=""/>&nbsp; نصب در ۷ قدم

<img src="readme-deploy.svg" width="100%" alt="Fork، Railway، آمستردام، Volume، پورت 8080، بدون خواب، Deploy"/>

> [!TIP]
> کل نصب حدود **۵ دقیقه** طول می‌کشه. فقط یه اکانت GitHub و یه اکانت Railway لازم داری.

| قدم | کار | نکته |
|:--:|---|---|
| **۱** | بالای همین صفحه **Star** و بعد **Fork** رو بزن | اسم ریپو هر چی خواستی |
| **۲** | توی [Railway](https://railway.com) بزن `New Project` ← `Deploy from GitHub repo` | ریپوی Fork شده‌ی خودت رو انتخاب کن |
| **۳** | `Settings` ← `Deploy` ← `Regions` ← **EU West (Amsterdam)** | کمترین پینگ از ایران |
| **۴** | روی سرویس راست‌کلیک (روی گوشی: نگه دار) ← `Attach Volume` با مسیر **`/var/lib/marzban`** | بدون Volume با هر Redeploy کاربرها پاک میشن |
| **۵** | `Settings` ← `Networking` ← `Generate Domain` با پورت **`8080`** | یه آدرس `xxxx.up.railway.app` می‌گیری |
| **۶** | مطمئن شو **Serverless / App Sleeping خاموشه** | وگرنه کانفیگ‌ها بعد از مدتی قطع میشن |
| **۷** | از تب `Deployments` یه **Redeploy** بزن | توی لاگ `[lock] xray test: config OK` یعنی همه‌چی آماده‌ست |

## <img src="readme-i-operators.svg" width="34" height="34" align="center" alt=""/>&nbsp; اپراتورها و سرعت

<img src="readme-operators.svg" width="100%" alt="بهترین کانفیگ برای هر اپراتور"/>

| اپراتور | اول اینا رو امتحان کن | اگه نشد |
|---|---|---|
| **همراه اول** | Ghost Anti-Filter · Ninja Stealth · Warp Speed | Swift Shield · Meteor |
| **ایرانسل** | Amsterdam Rocket · Lightning · Swift Shield | Quantum · Hyper Drive |
| **مخابرات (ADSL / فیبر)** | Amsterdam Rocket · Lightning · Vortex | Reality Pulse · Quantum · Ghost Anti-Filter |
| **رایتل** | Swift Shield · Meteor · Warp Speed | Ninja Stealth |
| **وای‌فای و اینترنت خوب** | Amsterdam Rocket · Lightning · Hyper Drive | Quantum · Reality Pulse |

> [!NOTE]
> همین جدول توی **صفحه‌ی ساب** هم هست: کاربر اپراتورش رو یه بار انتخاب می‌کنه (همراه اول، ایرانسل، مخابرات، رایتل یا وای‌فای)، کانفیگ‌های مناسبش میان بالای لیست و اولی برچسب «اول این رو بزن» می‌گیره. انتخابش هم برای دفعه‌ی بعد یادش می‌مونه. اگه سرور واسط ایران (Turbo Iran) گذاشته باشی، برای همه‌ی اپراتورها اول همونه.

> [!TIP]
> فیلترینگ هر روز فرق می‌کنه و هیچ کانفیگی همیشه برنده نیست. **ساده‌ترین راه:** توی اپ از همه‌ی کانفیگ‌ها **تست پینگ گروهی (Real Delay)** بگیر و کم‌پینگ‌ترین رو بزن.

### بهینه‌سازی‌های سرعت و پایداری (همه خودکار روشنن)

| قابلیت | کارش |
|---|---|
| **Early Data** (`ed=2560`) | اولین بسته همراه دست‌دادن میره؛ یه رفت‌وبرگشت کمتر سر هر اتصال |
| **`alpn=http/1.1`** | دقیقاً همون چیزی که لبه‌ی Railway می‌خواد، بدون مذاکره‌ی اضافه |
| **BBR** | سرعت ثابت‌تر روی اینترنت موبایل (اگه سرور اجازه بده) |
| **Heartbeat** | هر ۳۰ ثانیه یه ضربان کوچیک که اپراتور خط بیکار رو نبنده |
| **بستن QUIC** | مرورگر و یوتیوب روی TCP میرن که داخل تونل روون‌تره |
| **DNS سریع با IPv4** | جواب DNS از 1.1.1.1 و 8.8.8.8، بدون گیر کردن روی IPv6 |
| **بدون بافر** | بسته‌ها بدون مکث از nginx به Xray می‌رسن |
| **۱۶ هزار اتصال** | nginx برای هر worker تا ۱۶٬۳۸۴ اتصال، پنل شلوغ هم کند نمیشه |
| **بستن تبلیغات روی سرور** | دیتای کمتر، صفحه‌ها سریع‌تر باز میشن |
| **لینک ساده برای همه‌ی اپ‌ها** | هر اپ کانفیگ رو خودش می‌سازه؛ هیچ قالبی نمی‌تونه اتصال رو خراب کنه |
| **اتصال بیکار تا ۱۰ دقیقه** | وسط تماس، دانلود یا مکث ویدیو اتصال بسته نمیشه |
| **دست‌دادن ۱۰ ثانیه‌ای** | روی اینترنت ضعیف هم اتصال وسط راه رها نمیشه |

| `JINX_PATH_SECRET` | تصادفی | شناسه‌ی مسیر مخفی کانفیگ‌ها (`/cdn/<شناسه>`)؛ ۸ تا ۶۴ حرف، عدد یا `-`. یک بار ساخته می‌شه و ثابت می‌مونه |
| `JINX_OLD_PATHS` | `1` | `0` = مسیرهای قدیمی نسخه‌ی ۱۲ (`/panel-ws`، `/vless` و…) بسته می‌شن؛ بعد از به‌روزرسانی ساب همه |
| `JINX_HEARTBEAT` | `30` | ضربان WebSocket به ثانیه؛ `0` = خاموش |
| `JINX_BBR` · `JINX_ADBLOCK` · `JINX_FAST` · `JINX_REALITY` | `1` | `0` = خاموش |
| `JINX_XHTTP` | `1` | `0` = خاموش کردن XHTTP (Warp Speed و Quantum میرن روی HTTPUpgrade) |
| `JINX_MUX` | `0` | `1` = روشن؛ فقط برای v2rayNG با ساب JSON (Hiddify و Clash با Mux وصل نمیشن) |
| `JINX_TFO` | `0` | `1` = روشن کردن TCP Fast Open |
| `USE_CUSTOM_JSON_FOR_V2RAYNG` | `False` | `True` = ساب JSON کامل (با فرگمنت و Mux) برای v2rayNG؛ برای v2rayN، Streisand و Happ هم متغیر هم‌نام هست |

</details>

<a name="faq"></a>

## <img src="readme-i-faq.svg" width="34" height="34" align="center" alt=""/>&nbsp; عیب‌یابی و سوال‌ها

<details><summary><img src="readme-i-dot.svg" width="12" height="12" alt=""/>&nbsp; <b>کانفیگ‌ها وصل نمیشن یا پینگ نمیدن</b></summary><br/>

1. مطمئن شو دامنه با پورت <code>8080</code> ساخته شده و بعدش یه بار Redeploy زدی.
2. توی اپ <b>Update Subscription</b> بزن تا کانفیگ‌های تازه بیاد.
3. Mux رو توی اپ خاموش کن.
4. از <b>Real Delay</b> استفاده کن، نه TCP.
5. آدرس <code>/jx-status</code> رو باز کن و ببین کدوم بخش قرمزه.

</details>

<details><summary><img src="readme-i-dot.svg" width="12" height="12" alt=""/>&nbsp; <b>کانفیگ‌ها بعد از یه مدت قطع میشن</b></summary><br/>Serverless / App Sleeping رو از تنظیمات سرویس خاموش کن.</details>

<details><summary><img src="readme-i-dot.svg" width="12" height="12" alt=""/>&nbsp; <b>دیپلوی روی Healthcheck فیل میشه</b></summary><br/>پورت دامنه باید <code>8080</code> باشه. توی لاگ خط‌های <code>alembic</code> و <code>main.py</code> رو ببین.</details>

<details><summary><img src="readme-i-dot.svg" width="12" height="12" alt=""/>&nbsp; <b>رمز یادم رفته</b></summary><br/>متغیر <code>RESET_ADMIN_PASSWORD=1</code> رو بذار، Redeploy بزن، با <code>admin / admin</code> وارد شو و بعد متغیر رو پاک کن.</details>

<details><summary><img src="readme-i-dot.svg" width="12" height="12" alt=""/>&nbsp; <b>بعد از Redeploy کاربرها پاک میشن</b></summary><br/>Volume روی <code>/var/lib/marzban</code> وصل نیست.</details>

<details><summary><img src="readme-i-dot.svg" width="12" height="12" alt=""/>&nbsp; <b>ساب‌لینک <code>{SERVER_IP}</code> نشون میده</b></summary><br/>۲۰ ثانیه صبر کن و ساب رو آپدیت کن؛ نگهبان هاست خودش درستش می‌کنه.</details>

<details><summary><img src="readme-i-dot.svg" width="12" height="12" alt=""/>&nbsp; <b>روی اپراتور من کانفیگ مستقیم وصل نمیشه</b></summary><br/>Ghost Anti-Filter، Ninja Stealth یا Swift Shield رو امتحان کن. اگه باز نشد، Reality یا تانل کلودفلر.</details>

<details><summary><img src="readme-i-dot.svg" width="12" height="12" alt=""/>&nbsp; <b>پینگ بالاست</b></summary><br/>لوکیشن رو روی Amsterdam بذار، آدرس تست اپ رو <code>http://cp.cloudflare.com/</code> کن و Lightning یا Amsterdam Rocket رو بزن.</details>

<details><summary><img src="readme-i-dot.svg" width="12" height="12" alt=""/>&nbsp; <b>ذخیره‌ی Core Settings ارور 403 میده</b></summary><br/>عمدیه. اینباندها قفلن تا هیچ تغییری توی پنل کانفیگ‌ها رو خراب نکنه.</details>

<details><summary><img src="readme-i-dot.svg" width="12" height="12" alt=""/>&nbsp; <b>هزینه داره؟</b></summary><br/>خود پروژه کاملاً رایگانه. فقط هزینه‌ی Railway (طبق پلنی که داری) پای خودته.</details>

<details><summary><img src="readme-i-dot.svg" width="12" height="12" alt=""/>&nbsp; <b>اگه بقیه هم از این ریپو بسازن، سرعت من کم میشه؟</b></summary><br/>نه. هر Fork روی سرویس جداگانه‌ی خودش با CPU، رم و اینترنت جدا اجرا میشه.</details>
